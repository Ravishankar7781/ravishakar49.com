# ravishankar49.com

Ravishankar Kurma's site for **Zero to Data Analyst** (AnalytixAI): the free 12-week series, its roadmap, every week's free resources, and his portfolio.

## Pages

| Page | What it is |
| --- | --- |
| `index.html` | Home: the series, this week's card, resource buttons, comment keywords, how it works, modules, projects, skills with proof, About me |
| `roadmap.html` | Track your weeks: the live roadmap (a week unlocks every Monday) |
| `resources.html` | Every week's files (unlock by date) plus the open SQL practice packs |
| `kit.html` | CV and interview kit |
| `showcase.html` | Learner showcase |
| `portfolio.html` | Portfolio: skills with proof, projects, experience, education, certifications |
| `start.html` | START keyword page; `links.html` link-in-bio page |
| `week1.html` ... `week12.html`, `pack1.html`, `pack2.html`, `cv.html` | Short links for comment keywords |

## Each week (takes 2 minutes)

1. Upload that week's files to `files/week-0N/` (Week 1 is already in `files/week-01/`).
2. In `assets/content.js`, add them to that week's `files: [...]` list (copy the Week 1 entries as a pattern).
3. Optional: add the file sizes to `assets/sizes.js`.

Weeks unlock on their own at midnight UK time each Monday from Mon 2 Nov 2026. Nothing else needs changing.
